\# StudyBuddy – Project Scope



\## 1. Project Overview

StudyBuddy is a Python-based AI study assistant designed to collect, organise and retrieve educational knowledge from approved online sources. It aims to support students by providing relevant, accessible and structured learning information.



\## 2. Project Objectives

\- Collect educational content from approved knowledge sources.

\- Extract and organise relevant information using web scraping.

\- Build a structured knowledge base for educational content.

\- Support accurate retrieval of relevant learning materials.

\- Evaluate system responses using curated golden conversations.



\## 3. Core Components

\- \*\*Data Collection:\*\* Retrieve educational content from approved websites.

\- \*\*Web Scraping:\*\* Use Requests, BeautifulSoup and Selenium where appropriate.

\- \*\*Knowledge Base:\*\* Store and organise collected educational information.

\- \*\*AI Assistant:\*\* Use the knowledge base to support student enquiries.

\- \*\*Evaluation:\*\* Test system performance using predefined golden conversations.



\## 4. Technology Stack

\- Python 3.12

\- Requests

\- BeautifulSoup4

\- Selenium

\- Docker

\- Git and GitHub



\## 5. Project Structure

\- `data/` – Scraped knowledge-base data (excluded from Git).

\- `docs/` – Project documentation and golden conversations.

\- `studybuddy/` – Application source code.

\- `eval/` – Evaluation scripts and results.

\- `.venv/` – Python virtual environment.

\- `requirements.txt` – Project dependencies.

\- `.gitignore` – Files excluded from version control.



\## 6. Project Boundaries

The project will focus on educational information retrieval and study assistance. Data collection will use approved sources and respect website access restrictions. API keys and other credentials must not be committed to GitHub.



\## 7. Evaluation

System performance will be assessed using curated golden conversations, retrieval relevance, response accuracy and consistency.
